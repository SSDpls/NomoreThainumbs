# การทดสอบ (Testing)

## เทสต์อัตโนมัติ

รันด้วย:

```bash
dotnet test NoMoreThaiNums.slnx
```

พื้นที่ที่ครอบคลุม (60 เทสต์):

- **ThaiDigitConverter** — เลขไทยทุกตัวแม็ปไปเลขอารบิกถูกต้อง
  (`๐→0` … `๙→9`), ตัวอักษรที่ไม่ใช่เลขไทยไม่ถูกแตะ, ประโยคผสมไทย/ASCII
  (`จำนวน ๑๒๓ ชิ้น → จำนวน 123 ชิ้น`), ผลลัพธ์เป็น code point
  U+0030–U+0039 จริง, ปลอดภัยกับ null/ค่าว่าง
- **KeyboardProcessor** — key-down ที่ผลิตเลขไทยถูกแทนที่ (รวมชั้น Shift
  ซึ่ง Kedmanee จำเป็น), โหมดปิดผ่านทุกอย่าง, key-up ผ่าน, คอมโบ
  Ctrl/Alt/Win ผ่าน, event ที่ถูกฉีดผ่าน (ไม่เกิด recursion), พยัญชนะไทย
  เครื่องหมาย, เลขอารบิก และปุ่มที่ resolve ไม่ได้ ผ่านทั้งหมด
- **SettingsManager** — บันทึก/โหลดครบวงจร, ไม่มีไฟล์ → ค่าเริ่มต้น,
  JSON เสีย → ค่าเริ่มต้น, ไฟล์ว่าง → ค่าเริ่มต้น, JSON รูปร่างผิด →
  ค่าเริ่มต้น, สร้างไดเรกทอรีให้เองตอน save, พาธไฟล์ตั้งค่าถูกไดเรกทอรี
  ครอบ → ใช้ค่าเริ่มต้นแทนการ crash
- **SingleInstanceManager** — การ acquire ครั้งที่สองถูกปฏิเสธ, release แล้ว
  acquire ใหม่ได้, การส่งสัญญาณโดยไม่มีผู้ฟังเป็น no-op ที่ปลอดภัย

## เช็กลิสต์ทดสอบด้วยมือ (ต้องมี desktop session จริง)

Hook คีย์บอร์ดและการฉีดอินพุตไม่สามารถทดสอบอย่างมีความหมายในเทสต์อัตโนมัติได้
ให้ทำตามรายการต่อไปนี้โดยติดตั้งเลย์เอาต์ Thai Kedmanee และเปิดแอปทำงานอยู่

### การแปลงพื้นฐาน

| แอป | พิมพ์ | คาดหวัง |
|---|---|---|
| Notepad | `๑๒๓` (Shift+2, Shift+3, Shift+4) | `123` |
| Notepad | Shift+Q | `0` |
| Notepad | `ทดสอบภาษาไทย` | `ทดสอบภาษาไทย` (ไม่เปลี่ยน) |
| Notepad | `จำนวน ๑๒๓ ชิ้น` | `จำนวน 123 ชิ้น` |
| Windows Search | `๑๒๓` | `123` |
| File Explorer (rename) | `๑๒๓` | `123` |
| แถบ address ของ Chrome | `๑๒๓` | `123` |
| Word / Excel cell | `๑๒๓` | `123` |
| CMD / PowerShell | `๑๒๓` | `123` |
| แอปใด ๆ, เลย์เอาต์ Pattachote | `-` `2` `3` … | `1 2 3 …` |

### โหมดปิด (Disabled)

- เมนูถาด → เอาเครื่องหมายถูก **Enable** พิมพ์ `๑๒๓` ใน Notepad →
  ต้องได้เลขไทย `๑๒๓` กลับมา เปิดใหม่ → ได้เลขอารบิกอีกครั้ง
  ตรวจด้วยว่า tooltip ของถาดและบรรทัดสถานะในหน้าต่างตั้งค่าตามสถานะจริง

### Edge cases

- **Shift+ตัวอักษร, Ctrl+X/C/V, Alt+Tab, Win+L, Win+Space** —
  คีย์ลัดทุกตัวทำงานเหมือนไม่มีแอปพอดี
- **แถวเลขแบบไม่กด Shift (Kedmanee)** — ต้องยังได้พยัญชนะไทยแบบ
  `จ / - ภ ถ ุ ึ ค ต จ` (ไม่มีวันได้เลข) — เป็นการพิสูจน์ว่าชั้นไม่กด Shift
  ไม่ถูกแตะต้อง
- **กดค้างปุ่มเลข (auto-repeat)** — ได้ stream ของเลขต่อเนื่อง ไม่มีปุ่มค้าง
  ไม่มีการซ้ำซ้อน
- **พิมพ์เร็วโดยมีเลขปนในข้อความไทย** — ลำดับถูกต้อง ไม่มีตกหรือซ้ำ
- **คัดลอก/วางเลขไทย** — ข้อความที่วาง*ไม่*ถูกเขียนใหม่ (แปลงเฉพาะการพิมพ์จริง)
- **Num Lock / Caps Lock เปิดและปิด** — พฤติกรรมไม่เปลี่ยน เลข keypad ยังใช้ได้
- **สลับเลย์เอาต์ ไทย → อังกฤษ** — การพิมพ์อังกฤษไม่กระทบ สลับกลับ —
  การแปลงกลับมาทำงาน ถ้ามีหลายเลย์เอาต์ไทยติดตั้ง การสลับระหว่างพวกมัน
  ก็ยังให้การแปลงทำงาน
- **รีสตาร์ทแอป** — ค่าตั้งค่า (สถานะ enable, start-with-windows) ถูกจดจำ
- **เปิด Start with Windows แล้ว sign out/in** — แอปเริ่มในถาดอัตโนมัติ
  ปิดตัวเลือกแล้ว sign out/in — ไม่เริ่ม
- **เปิด exe ซ้ำ** — ไม่มีอินสแตนซ์ที่สอง หน้าต่างตั้งค่าของตัวที่รันอยู่
  ถูกดึงขึ้นมา
- **Exit** — ไอคอนถาดหาย, โปรเซสจบ (ตรวจใน Task Manager) และการพิมพ์
  กลับเป็นพฤติกรรมปกติทันที
